## Statement Forms

- `let` and `var` local declarations
- assignment
- `return`
- expression statements
- blocks
- `if` / `else if` / `else`
- `while`
- `for`
- `break`, `continue`
- `match`
- `attempt` / `handle`

There is no `switch`, no `case`, and no `default`.

## Local Declarations

```kira
let total = left + right     // inferred
var label: String            // declared, uninitialized
var ratio: Float = 0.8       // the initializer must already match
```

A declaration with no initializer is real but not readable until an assignment gives it a value. An annotated initializer is strict, so `var ratio: Float = 0` is rejected.

## Assignment

The left side names a place: a local, a field path, or an index expression.

```kira
state.width = 128
b.origin.x = 100
values[index] = next
```

Writing through a path requires `var` at every step, not just the last.

## Loops

`for i in a..b` walks a half-open integer range; `for x in xs` walks an array's elements. The bound expressions are evaluated once. The loop variable is a fresh immutable binding per iteration, scoped to the body.

A `for` is rewritten into a `while` during analysis, and `continue` still advances the loop because the rewrite steps the cursor before the body rather than after it.

`break` and `continue` outside a loop are reported rather than ignored.

## Match

```kira
match subject {
    Light -> return 1
    Tag(text) -> { print(text) }
}
```

An arm takes a single statement or a block. Variants are unqualified. A parenthesized name binds the payload as an owned immutable copy, visible only in its own arm.

| Rule | Code |
| --- | --- |
| Every variant covered | `KSEM129` |
| No variant matched twice | `KSEM127` |
| The subject is an enum | `KSEM125` |

There is no wildcard arm and no `else` arm. An exhaustive `match` whose arms all return is a definite return. A `break` inside an arm belongs to the enclosing loop.

## Attempt

```kira
attempt {
    let v = try fallible()
    return v * 2
} handle {
    TooSmall { return 0 - 1 }
    TooBig(reason) { return reason.count }
}
```

`try` is accepted in exactly one position: as the whole initializer of a `let` directly inside an `attempt` body (`KSEM137` elsewhere). A handler arm is `Variant { … }` with no arrow.

| Rule | Code |
| --- | --- |
| Every reachable failure variant handled | `KSEM139` |
| An arm names a variant of the failure enum | `KSEM140` |
| No failure handled twice | `KSEM142` |
| Every `try` in one `attempt` fails with the same enum | `KSEM141` |
| The `try` subject is `Result`-shaped | `KSEM138` |
| An `attempt` contains at least one `try` | `KSEM143` |

Statements after a `try` run only when it succeeded.

## Return

A function with a declared result type must definitely return one. An exhaustive `match` or a fully covered `attempt` counts.
