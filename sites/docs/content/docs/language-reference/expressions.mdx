## Primary Forms

- Integer, float, string, and boolean literals.
- Identifiers and qualified names (`Geo.Point`, `bindings.callbacks`).
- Grouped expressions.
- Array literals: `[1, 2, 3]`. Commas are optional where a newline separates the elements.
- Struct literals: `Vec3 { x = 1, y = 2, z = 3 }`. `:` is accepted for the field binder and the two may be mixed.
- Enum variants with a leading dot: `.Red`, `.Text("hi")`.
- Constructions: `Vec3(1, 2, 3)`, `Vec3(x: 1, y: 2)`, `Account()`, `Text(content: "hi")`.
- Closures: `{ value in return value + 1 }`, `{ in return 1 }`.
- `Task { call(args) }`.
- `MainThread.invoke { call(args) }`, `MainThread.spawn { call(args) }`, and `MainThread.post { call(args) }`.
- `quote { … }` and `#{ value }`, inside a `comptime macro` only.
- `nativeState(v)`, `nativeUserData(s)`, `nativeRecover<T>(t)`, `nativeUserDataRetain(t)`, `nativeUserDataRelease(t)`.

## Operators

```text
? :   ||   &&   |   ^   &   == !=   < <= > >=   << >>   + -   * / %
```

Loosest to tightest, exactly C's ladder. Unary `-`, `!`, and `~` bind tighter than every binary operator. The conditional nests to the right.

`move x` and `copy x` are prefix operators, recognized only when an operand follows. A range `a..b` is not an expression: it appears only in a `for` header.

`value is Type` and `value as Type` take a type on the right. They bind tighter than the comparisons and looser than the shifts, so `a is Point == b` tests first. `value` must be an `Any`; `is` answers whether it holds a `Type` by nominal runtime identity and releases the value, and `as` hands the held value back as an owned `Type`, trapping when it holds anything else. `Type` must be one an `Any` can hold: not `Void`, not `Any` itself.

## Calls

```kira
helper()
step(base: 1, tag: 9)                  // labeled, omitting a defaulted parameter
callbacks.invoke(add, 0, 5)            // through a namespace root
handler(0.016)                         // through a function-typed local
```

A positional call fills omitted trailing arguments from parameter defaults; a labeled call may omit any defaulted parameter.

### Trailing Blocks

A `{ … }` after a call is either a closure argument or a content block, decided by shape.

```kira
each { value in print(value) }          // a closure: it has an `in`
Row(gap: 8) { Text("a") Text("b") }     // a content block: bare children
doThing { return 1 } second: { return 2 } third: { return 3 }
```

A block with an `in` is a closure. A block whose first item is `name =` or `name :` is a struct literal. Everything else after a construction or a call with a content parameter is a content block, whose items are bare child expressions plus the `For(x in xs) { … }` and `if` builders. Later closures are labeled with the parameter name.

### Main-thread Operations

The three `MainThread` operations take one direct call in a trailing content block. The call must name a function marked `@MainThread`. `invoke` returns the target value, `spawn` returns a handle whose only property is `.await`, and `post` returns `Void`. Arguments and returned values are owned `Send` values.

A direct call to a `@MainThreadLifecycle` function is a start expression. It takes no arguments, returns `Void` after the event loop accepts the instance, and never executes the lifecycle body on the caller's application thread. Calls made from inside the lifecycle body are ordinary pinned calls on its preserved main-thread stack.

## Member Access and Indexing

```kira
rect.width
event.touches[index].pos_y
values[index]
values[index] = next
grid[1][1] = 77
```

Member access with no parentheses invokes a computed construct member, so `widget.node` reads the accessor and chains compose.

A `.count` on a `String` or an array is a property, never `.count()`.

## Enum Variant Resolution

A leading-dot variant resolves against the type expected at that position: a `let` annotation, a parameter, a return type, a struct field, or the other side of a comparison. In a position with no expected type, or against a non-enum type, it is `KSEM119`. Inside a `match`, variants are written unqualified.

## Assignment

Assignment is a statement, not an expression. See [Statements](/docs/language-reference/statements).
