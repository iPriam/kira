title: About the Language Reference
description: What the reference records, and how a refusal is written down.
---

The reference records the contract the compiler enforces: the tokens the lexer produces, the grammar shapes the parser accepts, the builtin names, and the rules semantics checks.

## How a Refusal Is Written

Every refusal names its diagnostic code, and the code is the stable part. A message may be reworded; `KSEM107` will always be a use after move.

A refusal is documented as a decision when the language takes a different route instead. `print(someStruct)` is `KSEM081` because no format for a struct is pinned anywhere, not because printing one is unimplemented. Where the reference says a shape is refused, it says what to write instead.

## What Is Not Here

Design that has not landed. A form the reference does not list is a form the parser does not accept.
