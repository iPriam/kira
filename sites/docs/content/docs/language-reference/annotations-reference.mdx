title: Annotations Reference
description: Every annotation the compiler answers to, where it is legal, and what it refuses.
---

An annotation is `@Name`, optionally with a `{ key: value; … }` block or a parenthesized list. There is no `annotation` declaration form; a program adds annotation-shaped surface through a [macro](/docs/macros) instead.

## Compiler Annotations

| Annotation | Target | Payload | Meaning |
| --- | --- | --- | --- |
| `@Main` | function | none | The entrypoint. One per application (`KSEM011`), none in a library (`KSEM255`), no parameters. |
| `@Runtime` | function | none | On a hybrid build, this body stays bytecode. |
| `@Native` | function | none | On a hybrid build, this body compiles to machine code. |
| `@Export` | function, class | none | The consumer-facing surface of a library package. `@Export` on a `struct` is `KPAR043`, in an application package `KSEM256`, on a method `KSEM167`, and with a payload `KSEM166`. |
| `@Derive(A, B)` | declaration | a name list | Runs each named derive macro over the declaration. `@Derive(X)` where `X` is not a derive-kind macro is `KMAC011`. |

`@Derive(Copy)` is answered by the compiler rather than by a macro: it generates nothing and asserts that the type is structurally copyable, reporting `KIR005` when a member or variant payload is not.

## Construct Member Annotations

Legal only inside a `construct` body. Any other name there is `KPAR061`.

| Annotation | Target | Meaning |
| --- | --- | --- |
| `@Required` | `let` | A value obligation a backed declaration discharges with a field or a computed member. A body on it is `KPAR062`. |
| `@Required` | `function` | A bodyless signature. A body on it is `KPAR065`. |
| `@Content` | `let` | A child slot filled by a construction's trailing block. Identical to writing the type `some X`. |
| `@Consuming` | `function` | A method that consumes its receiver. |
| `@Comptime` | a `lifecycle` hook | The hook runs during compilation instead of at run time. |

`@Required` on anything but a `let` or a `function` is `KPAR060`; `@Content` on anything but a `let` is `KPAR063`; `@Consuming` on anything but a `function` is `KPAR064`.

## FFI Annotations

| Annotation | Target | Required fields |
| --- | --- | --- |
| `@FFI.Extern` | bodyless function | `library`, `symbol`, `abi: c`. Repeatable `retains: <parameter>`. |
| `@FFI.Syscall` | bodyless function | `name`, written as `man 2` writes it. `library`, `symbol`, and `abi` are refused rather than ignored. |
| `@FFI.Struct` | struct | `layout: c` |
| `@FFI.Pointer` | struct | `target`, `ownership` |
| `@FFI.Array` | struct | `element`, `count` |
| `@FFI.Callback` | struct | `abi`, `params`, `result` |
| `@FFI.Alias` | struct | the aliased type |

A foreign declaration may not also be `@Main`, `@Runtime`, `@Native`, or `@Export`.

## Documentation

Documentation is not an annotation. Consecutive `///` comments above a declaration are its documentation, rendered by `kira doc`.
