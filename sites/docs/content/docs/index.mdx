Kira is a readable, ownership-aware language whose programs run identically on a bytecode VM, on LLVM-emitted machine code, on a hybrid of the two, and in a browser.

## What the Toolchain Does

- A frontend of `kira-source`, `kira-lexer`, `kira-macros`, `kira-parser`, `kira-semantics`, and `kira-ir`, shared by every backend and by the language server.
- A VM that executes bytecode and stays portable enough to build for `wasm32-unknown-unknown`.
- An LLVM backend that emits host executables, static archives, shared libraries, and cross-compiled images.
- A hybrid runtime that runs `@Runtime` bytecode beside `@Native` machine code in one process.
- Seamless C interop: a package lists its native libraries, declares bodyless `@FFI.Extern` functions, and calls them on every engine.
- `.ksl`, a separate shading language with GLSL, WGSL, HLSL, MSL, and SPIR-V backends.
- `kira live` for hot reload, `kira export` for per-platform projects, `kira profile` for sampled profiles, and `kira debug` for stopping a running program.

## Ground Rules for This Manual

Implemented behavior is stated as fact. A refusal is documented with the diagnostic code that fires. Nothing that does not exist is described as though it does.
