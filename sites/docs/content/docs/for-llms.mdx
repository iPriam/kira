## What Kira Is

Kira is an ownership-aware systems-and-apps language implemented as a Rust workspace. The same program runs on a bytecode VM (`kira run`), on LLVM-emitted machine code (`kira build --backend llvm`), on a hybrid runtime that mixes bytecode with native code, and on `wasm32-emscripten` (`kira build --device wasm32`). UI is expressed through construct families; shaders through the separate `.ksl` language.

## The Rule That Decides Correctness

Backend parity is a hard requirement. A feature works on every engine or is refused by a typed diagnostic. Never reason from "the VM does it, so it works". The [Execution and Feature Status](/docs/language-reference/execution-and-feature-status) matrix says which engines run each surface.

Do not invent syntax. If a form is not in the [Language Reference](/docs/language-reference), it is not accepted.

## Syntax That Does Not Exist

These appear in code generated by models trained on other languages and are all rejected:

| Written | Reality |
| --- | --- |
| `switch` / `case` / `default` | Not keywords. `match` dispatches on an enum's variants. |
| `_` or `else` arm in a `match` | No wildcard arm. Every variant is covered explicitly. |
| `?` for error propagation | The keyword is `try`, inside an `attempt { … } handle { … }`. |
| `I64`, `F64` | `Int` is the 64-bit integer and `Float` the 64-bit float. |
| `annotation Name { … }`, `capability` | Not declaration forms. |
| `@Printable` | `Printable` is a Foundation construct family, not an annotation. |
| `Widget Button { … }` | A construct-backed declaration is `construct Button(…) extends Widget { … }`. |
| `let r = 0..4` | A range is written only in a `for` header. |
| `class Sub` assigned to a `Base` binding | There is no subtyping (`KSEM063`). |
| A generic declaration member with its own type parameters | `KPAR047`; put the parameters on the enclosing function or aggregate declaration. |

## Conventions When Writing Kira

- A struct literal binds fields with `=`: `Vec3 { x = 1, y = 2 }`. `:` is accepted too.
- A class is built by calling it, never with a literal: `Savings()`.
- A construct family is a template; its name is not a type. Write `Any Widget` or `some Widget`.
- Ownership is explicit: a named non-trivial value passed to a consuming parameter needs `move`, and `copy` is the explicit non-consuming copy.
- `print` takes scalars and strings. `print(someStruct)`, `print(someArray)`, and `print(someEnum)` are `KSEM081`.
- Bitwise operators bind looser than equality, as in C. Write `(flags & 8) == 8`.
