Every form here is taken from a program in `examples/` or `tests-kik/`.

## An Entrypoint

```kira
@Main
function main() {
    print("hello from Kira")
    print(doubleValue(21))
    return
}

function doubleValue(value: Int) -> Int {
    return value + value
}
```

Exactly one function carries `@Main`, it takes no parameters, and the program is a directory of `.kira` files rather than one.

## Values

```kira
struct Vec3 {
    var x: Int
    var y: Int
    var z: Int
}

struct Box {
    var origin: Vec3
    var label: String = "unnamed"
}

let v = Vec3 { x = 1, y = 2, z = 3 }
var b = Box { origin = v }   // `label` takes its default
b.origin.x = 100             // a nested write lands in place
var copy = b                 // a deep copy: writing to `copy` leaves `b` alone
```

A struct is a value. An array and an enum are handles, so binding one moves it.

## Enums and `match`

```kira
enum Note {
    Blank
    Rank(Int)
    Tag(String)
}

function describe(n: borrow Note) -> Int {
    match n {
        Blank -> return 0
        Rank(value) -> return value
        Tag(text) -> return text.count
    }
}
```

A variant is written with a leading dot where the expected type says which enum it belongs to (`let n: Note = .Blank`), and unqualified inside a `match`. Coverage is checked, so an exhaustive `match` whose arms all return is itself a definite return.

## Ownership

```kira
function sum(v: borrow Vec3) -> Int { return v.x + v.y + v.z }
function consume(v: Vec3) -> Int { return v.x }

print(sum(v))            // a borrow reads and gives back
print(consume(move v))   // this takes `v` away
```

Five modes and no others: `owned` by default, `borrow`, `borrow mut`, `move`, and `copy`. A named non-trivial value must say `move` or `copy` at a call site that takes it.

## Traits

```kira
trait Hashable {
    function hash(borrow self) -> Int
    function doubled(borrow self) -> Int { return self.hash() * 2 }
}

struct Mesh: Hashable {
    let id: Int
    function hash(borrow self) -> Int { return id * 7 }
}
```

`:` is always conformance and `extends` is always a parent. A trait name in a type position is an existential over its conformers.

## Construct Families

```kira
construct Widget {
    @Required function render() -> String
    function announce() -> String { return "<" + render() + ">" }
}

construct Text(content: String) extends Widget {
    render { return content }
}

let items: [Any Widget] = [Text(content: "hi")]
for item in items { print(item.announce()) }
```

The parameter list tells a declaration from a template. A family is not a type, so a value of one is `Any Widget` or `some Widget`.

## Closures

```kira
function makeCounter(): () -> Int {
    var seen = 0
    return { in
        seen = seen + 1
        return seen
    }
}
```

A `let` is captured by value and a `var` is shared through a capture cell that outlives the frame.

## Error Handling

```kira
function process(n: Int) -> Int {
    attempt {
        let v = try clamp(n)
        return v * 2
    } handle {
        TooSmall { return 0 - 1 }
        TooBig { return 0 - 2 }
    }
}
```

`try` unwraps any enum with an `Ok` and an `Error` variant. Every reachable failure variant must be handled.

## Calling C

```kira
@FFI.Extern { library: ffimath, symbol: ffi_add, abi: c }
function add(a: I32, b: I32) -> I32

@Main function main() { print(add(20, 22)) return }
```

No `@Native`, no glue. The package lists `ffimath` in its manifest and the same source runs on the VM, on native code, and on both halves of hybrid.

## Macros

```kira
@Derive(Equatable, Serializable, Deserializable)
struct Point { var x: Int var y: Int }

let wire = serialize_Point(Point { x: 1, y: -2 })   // "Point{x:1,y:-2}"
```

Foundation's seven derive macros are Kira source, written on `comptime macro`; `@Derive(Copy)` is the eighth and the compiler's own, because it asserts a fact rather than generating code.
