This manual documents the Kira implementation in this repository. Read the guide chapters for an explanation in order, the reference chapters for one rule at a time, and the appendix for install, command, and platform workflows.

## Reading Order

1. [About Kira](/docs/about-kira)
2. [A Kira Tour](/docs/a-kira-tour)
3. [Language Guide](/docs/language-guide)
4. [Language Reference](/docs/language-reference)

If you are a language model or a coding agent, read [Kira for LLMs and Agents](/docs/for-llms) first: it is the dense version, and it lists the syntax that other languages have and Kira does not.

## Conventions

Kira code is fenced as `kira`, KSL as `ksl`, shell as `bash`, and manifests as `toml`.

A diagnostic code in the text names the exact refusal. `KSEM107` is a use after move; the prefix says which pass reported it. [Diagnostics](/docs/appendix/diagnostics) lists the prefixes.

Where a rule is a deliberate refusal rather than missing work, the manual says which alternative Kira takes instead.
