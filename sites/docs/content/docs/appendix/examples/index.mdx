Each directory under `examples/` is a readable program for one part of the language. Run any of them on any engine.

```bash
kira run examples/structs/structs.kira
kira run --backend llvm examples/structs/structs.kira
kira run --backend hybrid examples/structs/structs.kira
```

`crates/kira-cli/tests/backend_parity/examples.rs` builds them on all three engines, so an example whose output stopped matching fails a test rather than going stale.

## Language

| Example | Demonstrates |
| --- | --- |
| `hello` | `@Main`, typed functions, `print`, integer arithmetic. |
| `fib` | Recursion and `if`/`else`. |
| `loops` | `while`, `for` over a half-open range, `break`, `continue`, and operator precedence. |
| `strings` | Literals, concatenation, comparison, and string-returning functions. |
| `structs` | Stored members with defaults, nested writes, and the value semantics that make a copy independent. |
| `classes` | Inheritance, `override`, parent-qualified access, and flattening. |
| `enums` | Variants, payloads, and leading-dot construction. |
| `match` | Dispatch on a variant, binding a payload, and why this is not a `switch`. |
| `generics` | Generic enums and what each written instantiation names. |
| `arrays` | The shared growable handle and the ownership that comes with it. |
| `aliases` | `type Name = Target` as a second spelling. |
| `widths` | The fixed-width scalar spellings and the two things a spelling decides. |
| `bitwise` | The conditional expression and the bitwise operators. |
| `closures` | Function values, capture by value and by cell, and escaping closures. |
| `ownership` | Owned by default, `borrow`, `borrow mut`, `move`, and `copy`. |
| `attempt` | `attempt` / `try` / `handle` over a `Result`-shaped enum. |
| `imports` | File-scoped imports and namespace roots across several files. |
| `foundation` | `import Foundation` with no dependency entry. |

## Interop and Toolchain

| Example | Demonstrates |
| --- | --- |
| `ffi` | Calling C with no `@Native`: one manifest, one C source, one Kira file, four engines. |
| `library` | A Kira library and the Rust program that calls it, written to be read. |
| `networking` | Async operations started from a task body and joined through the cooperative scheduler. |
| `debug-lab` | A deliberately broken program for the debugger walkthrough. Its three `BUG` markers are logic faults, not traps. |

## Where to Start

- The smallest runnable program: `examples/hello`.
- The FFI seam end to end: `examples/ffi`, whose README carries the archive build commands.
- A library and its consumer: `examples/library`, whose README snippet was run against the generated crate before it was written down.
