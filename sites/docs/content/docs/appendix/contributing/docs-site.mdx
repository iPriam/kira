The site lives at `sites/docs/`. It is a Next.js App Router application built with [fumadocs](https://fumadocs.dev), and the package is named `kira-docs`.

## Structure

```text
sites/docs/
  app/                    the homepage, docs shell, API routes, and LLM endpoints
  content/docs/           every page, as .mdx
  lib/highlighting/       the Kira and KSL TextMate grammars
  mcp/                    the docs search MCP server
  source.config.ts        the fumadocs collection and Shiki configuration
```

`kira` and `ksl` are not bundled Shiki languages, so `source.config.ts` registers the repository's own TextMate grammars for ` ```kira ` and ` ```ksl ` fences. Every other language loads lazily from the bundle.

## Commands

```bash
cd sites/docs
bun install
bun run dev
bun run typecheck
bun run build
```

`typecheck` needs the generated collection types, which `build` writes, so run `build` at least once in a fresh checkout.

## Adding a Page

1. Add an `.mdx` file under the right folder in `content/docs/`, with `title` and `description` frontmatter.
2. Register its slug in the enclosing `meta.json` `pages` array. A new section needs its own `meta.json` with a `title` and a `pages` array, and its folder name registered in the parent's array.
3. Link to it from the section index.
4. Run `bun run build`.

A page missing from a `meta.json`, or a `meta.json` naming a page that does not exist, fails the build.

## Markdown Conventions

- Headings are literal noun phrases, not sentences or slogans.
- No em dashes and no prose arrows. Use punctuation or a second sentence.
- Lead with the conclusion; follow with the evidence.
- Prefer a table for short enumerable facts, a list when order or membership matters, prose otherwise.
- Name the diagnostic code when documenting a refusal, and say what to write instead.
- Delete a paragraph that does not change the reader's next move.

## Machine-Readable Output

The site exposes `/llms.txt`, `/llms-full.txt`, and `/docs/<path>.mdx`. Those are generated from the same content, so nothing has to be maintained twice.
