Two steps put a working toolchain on a machine.

```bash
curl -fsSL https://kira-lang.com/install.sh | sh   # the tools
knvm install latest                                # a compiler
```

Then:

```bash
kira new hello
cd hello
kira run
```

[Installation](/docs/appendix/getting-started/installation) covers the Windows route, the managed LLVM and libffi bundles, and installing from a checkout. [Running Programs](/docs/appendix/getting-started/running-programs) covers the commands you will use every day.

## What You Get

`kira` is a launcher. It resolves the selected toolchain and hands the process over, so `kira --version` reports the compiler and `knvm list` reports what is installed.

A toolchain is one directory holding the compiler, the language server, the live runner, the runtime archives, and Foundation. Moving it moves all of them together, and a version-skewed pairing of one toolchain's compiler with another's standard library is unreachable.
